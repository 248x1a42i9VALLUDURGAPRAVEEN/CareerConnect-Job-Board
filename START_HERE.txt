CAREERCONNECT FLUTTER JOB BOARD STARTER

1. Extract this ZIP.
2. In Android Studio, choose Open and select the extracted job_board_flutter folder.
3. Open Terminal in Android Studio.
4. Run: flutter pub get
5. Run: flutter run

If your Android folder was generated by `flutter create` and differs from the
provided manifest, keep the generated Android files and add this permission
inside the top-level <manifest> element:
<uses-permission android:name="android.permission.INTERNET" />

Run tests with: flutter test
Build APK with: flutter build apk --release

IMPORTANT:
- This is a starter project source ZIP, not a prebuilt APK.
- API access requires internet and the public API may change or impose limits.
- The application form is a demonstration validator only; it does not submit
  applications to employers or persist personal application data.
- Add your actual team names, screenshots, and defect log before submission.
